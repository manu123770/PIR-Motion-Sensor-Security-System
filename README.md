# PIR Motion Sensor Security System

This project is a PIR Motion Sensor Security System developed using Arduino UNO and simulated using Wokwi. The system detects human motion using a PIR sensor and turns ON an LED as an alert indication.

## Components Used
- Arduino UNO
- PIR Motion Sensor
- LED
- Resistor

## Software Used
- Wokwi Simulator
- Arduino IDE

## Applications
- Home Security
- Motion Detection
- Smart Security Systems
